Project overview

01

Learning to build a real ANC system

After studying and simulating active noise control in my ANC Practice Library, I started this prototype to develop the practical knowledge needed to build a physical system. That experience will provide a foundation for a more ambitious thesis project.

The system uses a reference microphone to sense the disturbance and an error microphone to measure the residual sound at the target location. An adaptive controller adjusts the control loudspeaker’s signal to reduce that residual. The project brings together the algorithm, synchronized audio I/O, and models of the acoustic paths.

System architecture

02

Acquisition, processing, and playback

Two INMP441 MEMS microphones provide the reference and error signals to a NUCLEO-F446RE. The output passes through a PCM5102 DAC and a TDA2030 amplifier to drive the control loudspeaker. The microphones and DAC share the audio clock.

I2S and circular DMA handle continuous acquisition and playback. Completed buffer halves are processed in the main loop, with a 1 ms interval per block. Clock and peripheral configuration use MCU registers.

Controller implementation

03

Adaptive filtering in C

The time-domain FxLMS controller combines three filters. W generates the control signal. G models the secondary path for adaptation, and F compensates for sound from the control loudspeaker reaching the reference microphone.

WAdaptive controller
Filters the reference and adapts through direct block correlation with the error.
GSecondary path
Uses the CMSIS-DSP FIR implementation to produce the filtered reference for adaptation.
FFeedback compensation
Estimates the loudspeaker’s contribution at REF so it can be removed from the reference signal.

Sample-rate conversion reduces the controller’s processing cost while keeping the audio interfaces at 48 kHz. Chebyshev II low-pass filters use cascaded biquads with independent states for the two microphones and the output.

The acoustic models come from REW measurements with a loopback timing reference. Their conversion to 8 kHz includes the firmware’s conversion filters, preserving timing and polarity and correcting for the measurement gain scale.

Current progress

04

Preparing for acoustic validation

Implemented and tested

Sample-rate conversion, the time-domain controller, and measured-model loading are implemented. The converter passed numerical validation, and basic DAC and both microphone passthrough tests worked in hardware. The firmware builds in Debug and Release.

The G64/F512/W576 candidate reached an observed maximum calculation time of 0.888 ms against a 1 ms budget, including conversion, across 256 benchmark blocks on the STM32 with -O3.

Work in progress

Testing the complete system

The measured-model configuration has not yet been flashed for a cancellation test. Acoustic cancellation on the physical system remains unvalidated.

The next checks are adaptation polarity, model timing equivalence, and sustained execution with audio and DMA active. Physical cancellation tests will start in the 100–500 Hz band.
